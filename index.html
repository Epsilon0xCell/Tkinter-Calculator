Tkinter-Calculator

Bench book, first bay. A small tkinter window, titled Area and Perimeter Calculator, 275 by 95 pixels, fixed in size, semi transparent where the window system allows it, black ground with white lettering and a Helvetica title. Stated clearly: despite the repository name this is not a general arithmetic calculator. It handles one rectangle only.

Open the repo Refusals

Bay 2

One job, walked through

Two empty entry boxes wait side by side, one for base and one for height. Decimals and padded spaces are accepted. Pressing the Calculate button writes one line underneath:

Area: 15, Perimeter: 16

That line is for a base of 5 and a height of 3, with trailing zeros trimmed. Float noise is tidied, so 0.1 by 0.2 reads Area: 0.02. Very large entries print in full: 1234567 by 7654321 gives Area: 9449772114007.

Bay 3

Refusals, exactly as phrased

An empty box, a word, or the text inf or nan returns: Please enter two numbers.

A side below zero returns: Base and height cannot be negative. Zero itself is allowed.

A note adds that results smaller than 1e-10 round to 0 at the print precision used.

Bay 4

Running and checking

python3 main.py
python3 -m unittest

Running needs Python 3 with tkinter and a real or virtual display. There is nothing to install beyond Python. Importing main.py opens no window, because the deciding function calculate_result sits apart from the widgets. The test command runs 12 tests over that function and its number formatting.

Bench note: the window itself went untested on a machine with no screen. The headless logic tests are what was verified.
