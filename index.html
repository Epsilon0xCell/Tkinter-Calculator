Tkinter-Calculator

A small Tkinter GUI calculator for a rectangle, and only for a rectangle: two entry boxes take a base and a height, pressing Calculate shows the area and the perimeter. Multiply the two measurements for the glass to cut; add them round for the moulding to run around it. Standard library only.

Open the repo The tests

Run it

python3 main.py

Requires Python 3 with tkinter and a display; there is nothing to install beyond Python itself. On a headless machine the window needs a virtual display (for example Xvfb) to open.

What it computes

Area: 15, Perimeter: 16  (base 5, height 3)
  • Two entry boxes take the base and the height. Both start empty.
  • Decimals are accepted, not just whole numbers, and surrounding whitespace is ignored.
  • Results print with trailing zeros trimmed, and a large product prints all its digits: 1234567 by 7654321 gives Area: 9449772114007.
  • If either box is empty or not a number, the result line shows Please enter two numbers and the window stays usable. The same message covers inf and nan, which float() accepts as text.
  • A negative base or height shows Base and height cannot be negative. Zero is allowed and computes as entered.

How it is built

The deciding code is separate from the window. calculate_result() in main.py takes the two entry strings and returns the exact text for the result label; the button handler only reads the boxes and shows that text. Importing main.py builds nothing, so the logic can be tested on a machine with no display.

The tests

python3 -m unittest

12 tests over calculate_result() and the number formatting: whole numbers, decimals, padded input, exponent input, zero, empty and text input, inf and nan, negative sides, the large product above, and float noise (0.1 by 0.2 reads Area: 0.02).

Honest limits

The window itself was not run in the recorded pass: the maintenance host has no display, so python3 main.py stops with a tkinter TclError there, and the GUI is recorded as not run rather than passed. The logic tests are what that pass verified. Results under 1e-10 in size round to 0 at the print precision used.
